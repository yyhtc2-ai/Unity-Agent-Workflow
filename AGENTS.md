# Repository instructions

This repository packages Agent Foundry, an optional collaboration skill, and a Codely MCP bridge. Preserve upstream license notices. Never include credentials, user configuration, conversation archives or task databases.

Codely delegation is opt-in per user-specified project/task. Installing, packaging or testing this repository does not authorize real Codely tasks. Do not delegate visual design/review or image generation/editing. Offline verification is `scripts/verify.ps1`.
